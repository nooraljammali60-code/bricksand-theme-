# ثيم Chocolate by Bricksand لسلة

هذا مصدر Twilight فعلي ومنفصل عن معاينة React. يستخدم منتجات وأسعار وروابط سلة الحية، ولا يحتوي كتالوج العرض المحلي.

## التشغيل
```bash
pnpm install
salla login
salla theme preview
```
ثم اختر متجرًا تجريبيًا مصرحًا واختبر الصفحة الرئيسية والبحث والخيارات والسلة والدفع المستضاف. للبناء: `pnpm production`.

## بوابة النشر
غير معتمد للنشر حتى ينجح تشغيل Salla CLI وفحص متجر sandbox فعلي. رفع GitHub وحده لا ينشر الثيم. بعد التحقق، اربط المستودع من بوابة شركاء سلة، راجع صلاحيات الثيم، ثم ابدأ مسار المراجعة الرسمي.

## الأقسام القابلة للترتيب
الفيديو، مود اليوم، السرد البصري، التصنيفات، المختارات، منتج الضوء، اكتشاف المكس، الهدايا، الآراء المعتمدة، القصص، FAQ/الثقة، وحكاية العلامة.

## غير متحقق في هذه البيئة
- لا توجد جلسة Salla CLI أو صلاحية متجر sandbox.
- يجب التحقق من شكل قيمة منتقي المنتجات المتعدد داخل محرر الثيم الحالي.
- يجب اختبار كل خيار منتج، نفاد المخزون، الخصم، الكوبون، الضريبة والشحن مع بيانات متجر حقيقية.
